## 这个模板的设计意图

**每一个字段都是给AI看的**，让AI能直接映射到代码：

| 模板字段 | AI生成什么 |
|---------|-----------|
| `系统代号: sga_rag` | Tool命名前缀 `sga_rag.*` |
| `鉴权方式: Bearer Token` | Connector的auth模块代码 |
| `HTTP方法: POST` + `路径: /retrieval/search` | `axios.post(baseUrl + '/retrieval/search', ...)` |
| `请求参数表` | `inputSchema`（JSON Schema + Zod验证） |
| `响应结构表` | `outputSchema` |
| `错误码表` | 错误归一化映射代码 |
| `需要确认: 是/否` | 是否在调用前加确认机制 |
| `异步: 是` | 是否走异步任务队列 |
| `示例` | 自动生成测试用例 |

**关键设计点：**

1. **`需要确认`字段** — 涉及资金/写操作的Tool标记为"是"，生成代码时自动加确认机制
2. **`异步`字段** — 标记为异步的Tool自动走任务队列，返回task_id
3. **`可重试`字段** — AI自动生成重试逻辑
4. **`示例`** — 直接变成测试用例的输入输出
